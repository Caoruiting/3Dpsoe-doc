# 基于扩散模型的后验推理用于高维黑箱优化

## 一、论文内容与核心功能
其核心内容是提出一种全新的高维黑盒优化框架。常常面临一个无法求导、计算代价极高的“黑盒”函数，需要找到使其输出最大化的输入参数。传统方法（如贝叶斯优化）在参数维度很高（成百上千维）时因“维度灾难”而失效。DiBO的核心功能就是在极高维空间中，用尽可能少的评估次数，找到黑盒函数的全局最优解。

## 二、核心贡献
1. 将候选点生成转化为后验推理问题：不再直接搜索最大化采集函数的点，而是构建一个目标后验分布： ptar(x)∝先验×奖励函数，并从中采样。
2. 利用扩散模型的强大表达能力：用扩散模型拟合数据分布（作为先验），用深度集成模型拟合函数值及不确定性（作为奖励/UCB）。
3. 提出高效的摊销采样与后处理策略：利用相对轨迹平衡（RTB）损失微调扩散模型，使其成为无偏的后验分布采样器，并配合局部搜索（梯度上升）和过滤策略来挑选候选点中的“峰值模式”。

## 三、面向2D图像3D人体姿态估计的完整工作流程
修改后的整体目标是：对每一张 2D 图片，利用扩散模型生成人体姿态候选，再利用代理模型和后验推断逐轮找到重投影误差最小、同时符合人体姿态分布的 3D 姿态。

### 完整执行步骤
1. **重置所有优化组件**
   每开始优化一张新图片，都重新建立空缓冲区，并把人体姿态扩散模型恢复到同一个预训练模型。上一张图片的缓冲区、代理模型和微调结果不直接带到下一张图片。

2. **生成初始候选姿态**
   使用预训练人体姿态扩散模型生成一批不同的 3D 姿态，例如 200 个。

3. **真实评价初始姿态**
   对每个初始姿态运行 IPO+PSO，计算它与当前 2D 关键点之间的真实重投影误差。误差越小，姿态越好。

4. **建立当前图片的缓冲区**
   保存每个候选姿态、真实重投影误差、奖励、IPO+PSO 参数和最终姿态结果。这些数据组成当前图片的初始缓冲区 $D_0$。

5. **把误差转换成奖励**
   将重投影误差转换成数值稳定的标准化奖励。重投影误差越小，奖励越高。这样可以避免奖励数值过大或过小。

6. **训练五个代理模型**
   五个代理模型都以“51 维候选 3D 姿态”为输入，以“该姿态经过 IPO+PSO 后得到的标准化奖励”为输出。
   五个模型结构相同，但使用不同的随机初始化和训练数据抽样。

7. **估计候选姿态的质量和不确定性**
   对一个新姿态，五个代理模型分别预测奖励。
   五个预测的平均值表示“这个姿态可能有多好”，五个预测的标准差表示“代理模型对这个姿态有多不确定”。

8. **计算 UCB 奖励**
   把预测平均值和不确定性组合起来：
这样既会选择预测效果好的姿态，也会尝试代理模型还不确定的姿态，避免过早陷入局部最优。

9. **更新人体姿态先验模型**
使用缓冲区中的姿态训练扩散先验 $p_\theta$。奖励高的姿态训练权重更大，奖励低的姿态训练权重更小。
为了防止模型只记住当前少量姿态，可以混入一部分 Human3.6M 训练姿态，保持正常人体姿态能力。

10. **建立当前图片的后验采样器**
 冻结 $p_\theta$，复制一份得到 $p_\psi$。
 $p_\theta$ 负责保证生成结果像正常人体姿态，$p_\psi$ 负责生成更符合当前 2D 图片的姿态。

11. **使用 RTB 训练后验采样器**
 使用两类数据训练 $p_\psi$：
 - 一半来自 $p_\psi$ 自己生成的完整扩散姿态。
 - 一半来自缓冲区中高奖励姿态的正向加噪轨迹。

 RTB 训练完成后，$p_\psi$ 会更容易生成“人体结构合理、预测重投影效果好”的姿态。

12. **生成大量后验候选**
 使用训练后的 $p_\psi$ 生成大量候选姿态，例如生成 100×B 个候选。
 这些候选暂时不运行昂贵的 IPO+PSO。

13. **使用代理模型进行快速评分**
 使用五个代理模型计算所有候选的平均预测奖励、不确定性和 UCB 奖励。
 这一步计算速度快，用来淘汰明显不好的候选。

14. **对候选进行局部优化**
 根据人体姿态先验和代理 UCB 奖励，轻微调整候选姿态，使它们更接近高质量区域。
 OIL 如果需要保留，可以放在这里作为独立的几何细化步骤，而不再放进每一个扩散去噪步骤中。

15. **筛选本轮候选**
 根据后验分数选择前B个候选。

16. **只评价筛选后的 B 个姿态**
 只对选出的B个姿态运行真实 IPO+PSO，得到真实重投影误差。
 这样不需要对所有大量候选都运行昂贵的 PSO。

17. **更新缓冲区**
 把本轮新评价的姿态和真实误差加入缓冲区。
 如果缓冲区超过最大容量L，就删除真实奖励最低的姿态，保留较好且有代表性的姿态。

18. **进入下一轮**
 使用更新后的缓冲区，重新训练五个代理模型、更新 $p_\theta$、训练 $p_\psi$、生成并筛选下一批候选。
