# 更深层的原因：优化目标是2D重投影误差，上下左右移动可以使重投影误差变小，不需要3D姿态形状变化。

## 一、如果初始姿态错了，就一直进化这个姿态。会不会跳不出坑？

优化 2D 关键点平均重投影误差时，算法可以通过调整整体平移、深度、射线投影位置，让 3D 点投影到 2D 后更贴近观测关键点，误差更小。可是单目 2D 到 3D 本来就有深度歧义：

- 同一个 2D 骨架  
  ↓  
  可能对应多个 3D 姿态  
  ↓  
  它们的 `avg_keypoint_error` 都很小  
  ↓  
  但其中一部分姿态和真实姿态不像

如果初始进化种群里"低投影误差的姿态样式"本身就和真实 3D 姿态很不一样，当前算法很容易陷在这个局部区域里。尤其当后续变异只是围绕精英姿态做小幅扩散加噪/去噪时，它更像是在"已经选中的姿态流形附近调位置、调深度、调投影去减少投影误差"，而不是主动去搜索另一种人体姿态样式。如果初始种群没有覆盖到真实姿态附近，单靠当前重投影误差进化，很可能跳不出这个坑。

## 二、怎么弄明白重投影误差和姿态的对应关系？

### 第一类：局部扰动敏感性分析

对同一个候选姿态，做受控扰动：

1. 只扰动 root 平移。
2. 只扰动全局 Z 深度。
3. 只扰动左臂深度。
4. 只扰动右腿深度。
5. 只扰动膝盖角度。
6. 只扰动躯干旋转。
7. 只扰动骨长。

每次重新跑投影误差，观察误差的变化。这样会得到一个很直观的结论：哪些 3D 变化对 2D error 敏感，哪些不敏感。

### 第三类：同一 2D 下采样大量 3D 候选，画低误差姿态簇

对一个固定 2D 关键点，从扩散模型采样很多候选，比如 5000 或 10000 个，不要只取 50 个。然后对 3D 姿态做 PCA，把每个点按投影着色。可能会看到低 error 区域可能不是一个点，而是多个簇。真实 3D 姿态可能在其中某一个簇里，但当前进化选中的可能是另一个低 2D error 的错误簇。

这个分析它能回答：

- 低投影误差的姿态空间到底有几个模式？
- 真实姿态所在模式是否被初始采样覆盖？
- 当前进化是否只在其中一个模式里收缩？

## 三、修改代理模型

如果只有 2D 关键点，歧义很难消除。但如果在代理模型上加原图，可以利用图像特征，比如 2D keypoints 只给了手腕坐标，但图像可能能看出手臂是在身体前面还是后面。这个信息不在投影误差里。

1. **修改损失函数**：主损失使用负对数似然 NLL。
2. **修改数据集**，多增加几个姿态。保持一个 2D 姿态对应至少 3 个 3D 姿态。并且保持数据集中一个 2D 姿态对应的 3 个 3D 姿态很不相同。
3. **补条件信息**：fitness 来自重投影误差，但训练输入里没有 `camera_K`，只有 `pose_2d` 和 `child_pose`。相机内参会直接改变 3D 候选投到 2D 后的误差。建议把 `camera_K` 编码进模型，至少用一个小 MLP 得到条件向量后和 `pose`/`child` 特征融合。否则模型很容易学成"看起来差不多"的打分器。
