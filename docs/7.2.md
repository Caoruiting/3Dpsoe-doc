# 3D 姿态扰动敏感性分析报告

## 1. 实验数据集概述
本次实验共包含 213 行数据（1 行表头 + 212 行实验记录），每行对应一次受控扰动实验的完整结果，用于量化不同姿态参数变化对 2D 重投影误差的影响程度。

## 2. 数据字段定义
### 2.1 实验标识字段（前 6 列）
| 字段名 | 含义说明 | 取值示例 |
|--------|----------|----------|
| `perturb_type` | 扰动类型名称，共 18 种 | `global_depth`、`root_trans`、`torso_rot_y` |
| `body_part` | 扰动影响的身体部位，共 7 种 | `whole`（全身）、`left_arm`（左臂）、`right_leg`（右腿） |
| `magnitude` | 扰动幅度数值 | 10、25、50、100、200、500、1000 |
| `sign` | 扰动方向 | 1 = 正向扰动，-1 = 负向扰动 |
| `unit` | 扰动单位 | `mm`（毫米，平移/深度）、`deg`（度，旋转）、`pct`（百分比，骨长缩放） |
| `baseline_w` | 基准加权重投影误差，所有样本基准一致 | 约 99.90 像素 |
| `baseline_u` | 基准未加权重投影误差，所有样本基准一致 | 约 99.90 像素 |

### 2.2 整体误差结果字段
| 字段名 | 含义说明 |
|--------|----------|
| `perturbed_w` | 扰动后的加权重投影误差 |
| `perturbed_u` | 扰动后的未加权重投影误差 |
| `delta_w` | 加权误差变化量（扰动后值 − 基准值） |
| `delta_u` | 未加权误差变化量（扰动后值 − 基准值） |

### 2.3 逐关节误差字段
共 34 列，覆盖 17 个身体关节，每个关节对应 2 列数据：
- `per_joint_0` ~ `per_joint_16`：扰动后单个关节的 2D 投影误差（单位：像素）
- `delta_joint_0` ~ `delta_joint_16`：单个关节的误差变化量（单位：像素）

## 3. 扰动类型明细
实验覆盖的核心扰动维度分为 5 大类：
- **全局刚体变换类**：`global_depth`（全局 Z 轴深度）、`root_trans`（根节点整体平移）
- **躯干旋转类**：`torso_rot_z`、`torso_rot_y`（躯干绕对应坐标轴旋转）
- **肢体关节类**：`knee_right_z`、`knee_left_z`（左右膝关节绕轴旋转）
- **肢体深度类**：`left_arm_depth`、`right_leg_depth`（单肢体独立深度偏移）
- **骨骼长度类**：`bone_l_hip_knee`、`bone_r_hip_knee`、`bone_l_shoulder_elbow`（单段骨骼长度缩放）

## 4. 重投影误差敏感性分析
### 4.1 图表说明
![Max |delta_w| 排序图](tmp/1194753403394_docxword_media_image2.png)
*图 1：各扰动类型对 2D 重投影误差的影响幅度排序*

该图表用于回答核心问题：**哪些姿态参数扰动对 2D 重投影误差的影响最大？**

- 横轴：`Max |delta_w|`（单位：像素），表示该扰动类型在所有测试幅度下，加权误差变化的最大绝对值
- 纵轴：扰动类型 + 幅度 + 单位，例如 `root_trans 200mm` 表示根节点整体平移 200 毫米
- 柱长含义：柱子越长，代表该参数变化对 2D 重投影误差的敏感性越高

### 4.2 敏感性排序结论
#### 高敏感性参数（对误差影响显著）
1.  全局深度变化 1000mm：对 2D 重投影误差的敏感性最高
2.  根节点平移 200mm、全局深度变化 500mm：敏感性次之

#### 低敏感性参数（对误差影响微弱）
右膝 Z 轴旋转 10 度、左臂深度偏移 200 毫米、左膝 Z 轴旋转 20 度、右腿深度偏移 150 毫米。

### 4.3 整体规律
**2D 重投影误差对全局位置变化（深度、整体平移）和躯干朝向非常敏感，但对局部肢体的深度变化和骨骼长度变化不敏感。**
