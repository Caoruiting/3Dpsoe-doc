# 3D 姿态扰动敏感性分析报告

## 1. 实验数据集概述
本次实验数据共包含 213 行（1 行表头 + 212 行实验数据），每行数据对应一次受控扰动实验的完整结果，用于量化不同姿态参数变化对 2D 重投影误差的影响程度。

## 2. 数据字段定义
### 2.1 实验标识字段（前 6 列）
| 英文字段名 | 中文含义 | 取值示例（英文+中文） |
|------------|----------|----------------------|
| `perturb_type` | 扰动类型名称，共 18 种 | `global_depth`：全局Z深度变化<br>`left_arm_depth`：左臂深度变化<br>`right_leg_depth`：右腿深度变化<br>`knee_right_y`：右膝绕Y轴旋转<br>`torso_rot_y`：躯干绕Y轴旋转 |
| `body_part` | 扰动影响的身体部位，共 7 种 | `whole`：全身<br>`left_arm`：左臂<br>`right_leg`：右腿 |
| `magnitude` | 扰动幅度数值 | 10、25、50、1000 |
| `sign` | 扰动方向符号 | 1：正向扰动<br>-1：负向扰动 |
| `unit` | 扰动单位 | `mm`：毫米<br>`deg`：度<br>`pct`：百分比 |
| `baseline_w` | 基准加权重投影误差（所有行基准一致） | 约 99.90 像素 |
| `baseline_u` | 基准未加权重投影误差（所有行基准一致） | 约 99.90 像素 |

### 2.2 整体误差结果字段（共 4 列）
| 英文字段名 | 中文含义 |
|------------|----------|
| `perturbed_w` | 扰动后的加权重投影误差 |
| `perturbed_u` | 扰动后的未加权重投影误差 |
| `delta_w` | 加权误差变化量（扰动后值 − 基准值） |
| `delta_u` | 未加权误差变化量（扰动后值 − 基准值） |

### 2.3 逐关节误差字段（共 34 列）
覆盖 17 个身体关节，每个关节对应 2 列数据：
- `per_joint_0` ~ `per_joint_16`：扰动后单个关节的 2D 投影误差，单位：像素
- `delta_joint_0` ~ `delta_joint_16`：单个关节的误差变化量，单位：像素

## 3. 重投影误差敏感性分析
### 3.1 图表说明
![Max |delta_w| 排序图](tmp/1194753403394_docxword_media_image2.png)
*图 1：各扰动类型对 2D 重投影误差的影响幅度排序*

该图表用于回答核心问题：**哪些扰动对 2D 重投影误差的影响最大？**

- 横轴：`Max |delta_w|`，单位：像素，表示该扰动类型在所有测试幅度下，加权误差变化的最大绝对值
- 纵轴：扰动类型 + 幅度 + 单位，例如 `root_trans 200mm` 表示根节点整体平移 200 毫米
- 柱长含义：柱子越长，代表该参数变化对 2D 重投影误差的敏感性越高

### 3.2 敏感性排序结论
#### 高敏感性参数（对误差影响显著）
1.  `global_depth 1000mm`：全局深度变化 1000 毫米，对 2D 重投影误差的敏感性最高
2.  `root_trans 200mm`：根节点平移 200 毫米、`global_depth 500mm`：全局深度变化 500 毫米，敏感性次之

#### 低敏感性参数（对误差影响微弱）
右膝Z轴旋转 10 度、左臂深度偏移 200 毫米、左膝Z轴旋转 20 度、右腿深度偏移 150 毫米。

### 3.3 整体规律
**2D 重投影误差对全局位置变化（深度、整体平移）和躯干朝向非常敏感，但对局部肢体的深度变化和骨骼长度变化不敏感。**
